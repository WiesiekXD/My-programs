## 🔐 INFORMACJE O DOSTĘPIE
Wszystkie chronione hasłem archiwa używają haseł z międzynarodowymi znakami, aby zapobiec przypadkowemu uruchomieniu przez niedoświadczonych użytkowników.

**Typowe wzorce haseł:**
- Znaki serbskie/cyrylica (np. "Prišla Džuli")
- Specjalne znaki Unicode
- Niestandardowe układy klawiatury

*Celowa złożoność służy jako dodatkowa warstwa bezpieczeństwa*
